# RobloxSHT

Roblox project managed with [Rojo](https://rojo.space/).

## Development

1. Open project in Roblox Studio.
2. In terminal run:
   ```bash
   rojo serve
   ```
3. Connect via the Rojo plugin in Roblox Studio.

## Auto-deploy

Every push to `main` branch builds the place and deploys it to Roblox via GitHub Actions and Open Cloud API.
